## 🛠️ Setup & Usage

### Prerequisites

- **Web Browser** (Chrome/Firefox recommended)
- **Code Editor** (VS Code recommended)
- **Node.js** (Optional, for running .js files)

### Running the Code

1. **Clone the repository**
   ```bash
   git clone https://github.com/prabhatyadav4/javascript-bootcamp.git
   cd javascript-bootcamp
   ```

2. **For HTML Projects**
   ```bash
   # Navigate to project folder
   cd 08_PROJECTS/01_ColorChanger
   
   # Open index.html in browser
   open index.html
   # OR use Live Server in VS Code
   ```

3. **For JavaScript Files**
   ```bash
   # Using Node.js
   node 01_BASICS/01_variables.js
   
   # OR open browser console and paste code
   ```

### Recommended VS Code Extensions

- Live Server
- JavaScript (ES6) code snippets
- Prettier - Code formatter
- ESLint
